04Incident comics

Real outages from production, told in four panels. Each one started as “service down”. Each real cause was hiding underneath.

The nightly job that ate /tmp MinIO · object storage

  1. 1 · The page

    BEEP!

    MinIO-down page on a production cluster.

  2. 2 · The digging

    df -h showed /tmp at 100%. A daily mlocate (updatedb) cron job was indexing millions of object paths.

  3. 3 · The twist

    Rebuilding its ~5 GB index needed ~10 GB of temp space. That filled the 10 GB /tmp and left MinIO stuck.

  4. 4 · The fix

    Freed the space and removed mlocate: nothing on a storage server needs locate. It never came back.

    RESOLVED

Moral of the storyAlert on the cause (disk), not just the symptom (service).

One bad disk, zero lost bytes MinIO · erasure coding

  1. 1 · The page

    BEEP!

    MinIO-down alerts on a production cluster.

  2. 2 · The digging

    MinIO logs, dmesg, lsblk, filesystem checks. One disk's filesystem was corrupted, and partition recovery failed.

  3. 3 · The insight

    MinIO ran distributed with erasure coding, so no data lived only on that disk.

  4. 4 · The fix

    Wiped, reformatted and remounted it, then let MinIO self-heal the shards from the cluster. Zero data loss.

    RESOLVED

Moral of the storyWhen the redundancy exists, heal from parity instead of nursing doubtful hardware.

150 million vectors, rebuilt from the truth Milvus · etcd · MinIO · ClickHouse

  1. 1 · The page

    BEEP!

    A server under the face-matching Milvus cluster filled its disk under live production traffic.

  2. 2 · The damage

    Writes failed halfway. Segment objects in MinIO no longer matched the metadata in etcd, and reconciling them failed.

  3. 3 · The insight

    The embeddings were never the source of truth. Every one also lived in ClickHouse.

  4. 4 · The fix

    Wiped Milvus, MinIO, etcd and Pulsar, re-ingested ~150M embeddings from ClickHouse and rebuilt the indexes. No permanent data loss.

    RESOLVED

Moral of the storyMake every serving store rebuildable from a durable system of record.

Build the platform

  • Multi-tenant Kubernetes on EKS, AKS and OKE. One shared cluster per environment with per-product node pools, Istio ambient mTLS, Envoy Gateway, External Secrets and per-product HAProxy database proxies. Cluster Autoscaler right-sizing cut node compute by 25%.

  • A policy-gated k8s deploy CLI that renders, then runs kubeconform, Kyverno and kube-score before Helm applies anything. New-service onboarding went from days to under 2 hours.
  • GitOps with ArgoCD ApplicationSets and a Config Management Plugin running the same render pipeline, with Argo Rollouts evaluated for canary releases and metric-based rollback.
  • AI infrastructure: vLLM inference on NVIDIA GPUs in AWS for face matching and document extraction, and Milvus vector search over 150M+ face embeddings.

Codify everything

  • Landing zones on three clouds from one Terraform codebase. Hub-and-spoke on AWS, Azure and OCI, about 15 layers per estate with independent state, driven by YAML with JSON Schema validation and plan-time guardrails.
  • Imported a live Cloudflare account to zero diff: 500+ DNS records plus Zero Trust Access, Tunnels/WARP and Gateway, using bulk import blocks, an auto-reconcile drift pipeline and terraform test gates.
  • Seven platforms as code (AWS, Azure, OCI, Cloudflare, GitLab, FortiGate and Nexus) with reusable multi-backend modules. Provisioning time dropped 75%.
  • Ansible-built HA clusters of 20+ stateful tools (Patroni, MongoDB, Redis, etcd, Kafka, Pulsar, ClickHouse, Milvus, Qdrant, MinIO, Consul, Vault) across RHEL, Oracle Linux, Ubuntu and Amazon Linux, at 99.9% uptime.
  • A config-driven Jenkins framework across 3+ controllers: one versioned Groovy library, each job a schema-checked YAML file plus a 3-line Jenkinsfile, generated by Job DSL. 50+ jobs, pinned per environment for one-line rollback, with gitleaks, shellcheck and approval gates built in.

Cut cost & risk

  • Monthly cloud spend down about 20% through backup/DR, observability and cost audits of the managed clusters.
  • Customer-managed-key encryption everywhere, with SOPS/age keeping secrets out of Terraform state, supporting PCI DSS.
  • HashiCorp Vault across 100+ production VMs, removing hardcoded credentials; moved Docker deployments to Kubernetes and cut deployment time by 65%.
  • Self-hosted GitLab, Nexus, SonarQube, Listmonk and WireGuard, cutting third-party licensing by 40%.
  • AI-assisted, human-verified. I use Claude daily for debugging, root-cause analysis and tooling; every suggested change is reviewed and validated before it reaches production.
